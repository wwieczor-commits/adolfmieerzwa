# Szlak kaprala Mierzwy

Strona pamięci kaprala Adolfa Mierzwy (1939–1947): łagry NKWD, armia gen. Andersa, 1. Dywizja Pancerna gen. Maczka i powrót do kraju.

Powstała na podstawie książki Zofii Wieczorek „Z Przemyśla do Szczecina przez trzy kontynenty. Wojenny szlak kaprala Adolfa Mierzwy” (Wydawnictwo Edytorial).

- `index.html` – cała strona (HTML, CSS i JavaScript w jednym pliku)
- `img/` – zdjęcia z archiwum rodzinnego i z książki
